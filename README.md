# Crypto Trading Demo Platform

## 📌 О проекте

Это учебный проект — демо-платформа для симуляции торговли криптовалютой в реальном времени.

Пользователь сможет:

- работать с виртуальным портфелем
- покупать/продавать криптовалюту по рыночным ценам
- отслеживать изменения баланса и активов
- использовать дополнительные трейдинг-функции (в разработке)

Проект создаётся как SPA без использования React, на чистом TypeScript.

---

## ⚙️ Текущий этап разработки

Сейчас проект находится на ранней стадии:

- настроен TypeScript
- подключены линтеры (ESLint / Stylelint)
- базовая структура проекта
- подготовка архитектуры под SPA

## 🧱 Планируемый стек

Пока стек не финализирован, но планируется:

- TypeScript (основной язык)
- Vanilla JS архитектура / SPA подход без фреймворков
- API для получения крипто-данных в реальном времени
- LocalStorage / Cookies (на ранних этапах)
- В будущем: база данных + авторизация пользователей
